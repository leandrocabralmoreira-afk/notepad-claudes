Notepad4 portatil (barra de formatacao Markdown)

Basta manter Notepad4.exe e Notepad4.ini na mesma pasta. As configuracoes
ficam no .ini (nada e gravado no registro).

Barra de formatacao: selecione um texto e aguarde ~0,3 s; a barra aparece acima da selecao.
Clicar de novo no mesmo botao remove a formatacao.
  Realce      -> <mark>texto</mark>
  Negrito     -> **texto**
  Italico     -> *texto*
  Sublinhado  -> <u>texto</u>
  Marcadores  -> "- "      Lista numerada -> "1. "
  Tachado     -> ~~texto~~
  Limpar      -> remove todos os marcadores acima, de lista e de titulo

Imagens: copie uma imagem e use Ctrl+V; o editor insere
![imagem](data:image/png;base64,....) no texto (Markdown).
